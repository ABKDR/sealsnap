# SealSnap

Пассивные снимки публичных веб-страниц с манифестом SHA-256, по которому пакет можно проверить
позже.

## Что делает программа

SealSnap получает адрес страницы, скачивает ее по строгим сетевым правилам, отрисовывает в Microsoft
Edge с выключенными скриптами и сохраняет результат папкой из пяти файлов. В одном из них,
`manifest.json`, записаны размер и хэш SHA-256 остальных четырех. Команда `verify` потом сверяет
папку с манифестом и отвергает пакет при любом расхождении.

Программа работает в Windows 10 и 11 и пользуется уже установленным Edge. Для повседневной работы
есть окно, для сценариев есть командная строка.

## Зачем это нужно

Юристу, регулятору, исследователю или журналисту бывает нужно показать, что было на странице, когда
он ее открыл. Одиночный скриншот легко оспорить. SealSnap собирает в один пакет исходный ответ
сервера, страницу в том виде, в каком ее построил браузер, картинку и журнал запросов. Позже по
пакету можно доказать, что с момента снимка ни один файл не менялся. Если отпечаток манифеста
хранится отдельно от пакета, можно показать и то, что пакет не подменили целиком.

## Как устроена работа

1. Адрес проверяется до любого обращения в сеть. Принимаются только `http` и `https` на стандартных
   портах 80 и 443, без имени пользователя и пароля, длиной до 4096 знаков.
2. Страницу скачивает собственный клиент SealSnap. Имя хоста разрешается до соединения, и каждый
   адрес IPv4 в ответе DNS должен быть публичным; одного частного или служебного адреса достаточно
   для отказа. Соединение идет на проверенный адрес без повторного запроса к DNS. Каждое
   перенаправление, их не больше пяти, проверяется заново. Отправляются только запросы GET.
3. Edge отрисовывает страницу пассивно. Он запускается без окна, с включенной песочницей и чистым
   временным профилем, JavaScript выключен. Своей сети у браузера нет. Он переведен в режим офлайн,
   а его прокси указывает на местный сервер, который отвечает отказом на любой запрос. Саму страницу
   Edge получает из уже скачанных байтов. Таблицы стилей, картинки и шрифты, которые он запрашивает,
   SealSnap скачивает сам по тем же правилам. Прочие запросы блокируются и попадают в метаданные, до
   100 записей.
4. Исходный ответ, DOM после отрисовки, снимок PNG, метаданные и манифест записываются в новую
   папку. Перед сообщением об успехе программа один раз проверяет готовый пакет.
5. Команда `verify` в любой момент позже перечитывает папку и сверяет каждый файл с манифестом. HTML
   при этом в браузере не открывается.

## Состав пакета

| Файл | Что внутри |
|---|---|
| `source.html.txt` | тело ответа сервера в том виде, в каком оно пришло |
| `rendered.html.txt` | DOM после пассивной отрисовки в UTF-8 |
| `screenshot.png` | картинка шириной 1280 px и высотой от 900 до 6000 px |
| `metadata.json` | запрошенный и конечный адрес, статус HTTP, адрес IPv4 сервера, перенаправления, сделанные и заблокированные запросы, время начала и конца в UTC по часам компьютера, версия Edge, режим отрисовки |
| `manifest.json` | метка формата, размеры и SHA-256 четырех файлов выше |

HTML хранится с расширением `.txt`, чтобы двойной щелчок открывал его как текст и не запускал в
браузере. Папка пакета называется `snapshot-` и случайный идентификатор. Существующие пакеты
программа не перезаписывает и не удаляет. Адрес страницы попадает в метаданные, поэтому ссылки с
секретными токенами снимать не стоит.

## Установка

Нужны Windows 10 или 11, актуальный Microsoft Edge и Python 3.12 с модулем `tkinter` (он нужен только
окну). Браузер программа не скачивает и пользуется установленным Edge.

Через `uv`, из папки проекта:

```powershell
uv venv --python 3.12 .venv
uv pip sync --python .venv/Scripts/python.exe --require-hashes --only-binary :all: requirements.lock
```

Через pip, в окружении Python 3.12:

```powershell
python -m pip install --require-hashes --only-binary :all: -r requirements.lock
```

Все зависимости закреплены точными версиями и хэшами в `requirements.lock`. `START.vbs` ищет
окружение в папке `.venv` внутри проекта. В `pyproject.toml` объявлена и консольная команда
`sealsnap`; она появляется после установки самого проекта в окружение.

## Работа с программой

### Окно

Дважды щелкните `START.vbs`. Окно откроется без терминала. Если окружения `.venv` нет, появится
сообщение, и запуск остановится. То же окно открывает команда `python -m sealsnap gui`.

Вставьте адрес, выберите папку и нажмите «Сохранить снимок». По окончании окно покажет путь к пакету
и отпечаток манифеста, а кнопка «Открыть папку» откроет пакет. Кнопка «Выбрать и проверить пакет»
проверяет любую папку пакета. Если отпечаток сохранен раньше, вставьте его в поле над этой кнопкой,
и пакет сверится еще и с ним. Сбор прерывают кнопка «Отменить» или закрытие окна.

Интерфейс окна пока только русский. Английский интерфейс стоит первым пунктом в планах.

### Командная строка

```powershell
python -m sealsnap capture https://example.com --output captures
python -m sealsnap verify captures/snapshot-<id>
python -m sealsnap verify captures/snapshot-<id> --expected-sha256 <отпечаток>
```

Результат печатается в JSON. Успех дает код выхода 0 и `ok: true`. Ожидаемый отказ, например опасный
адрес, достигнутый предел или несовпавший файл, дает код 2 и `ok: false` с коротким кодом ошибки
вроде `NON_PUBLIC_ADDRESS` или `FILE_DIGEST_MISMATCH:source.html.txt`.

Без `--output` пакеты ложатся в папку `captures` рядом с каталогом модуля `sealsnap`. При запуске из
исходников это папка проекта.

## Что доказывает проверка и чего она не доказывает

Проверка доказывает, что размеры и хэши SHA-256 четырех файлов совпадают с записанными в
`manifest.json`, что в папке нет лишних или недостающих файлов и нет символических ссылок, точек
соединения и жестких ссылок. Без внешнего отпечатка это согласованность файлов, а не подлинность.
Кто изменит файл и перепишет манифест под него, проверку пройдет. Если отпечаток манифеста сохранили
отдельно при снимке и передали в `--expected-sha256`, замена всего пакета тоже обнаружится.

Время снимка проверка не доказывает. Оно берется с часов компьютера и ничем не удостоверено,
манифест не подписан, служба меток времени не вызывается. Не доказывает она ни авторства снимка, ни
того, что другие посетители видели ту же страницу. За полноту страницы она тоже не ручается:
скрипты, фреймы и формы выключены, и страницы, собранные скриптами, могут выглядеть неполно.
Нотариального удостоверения SealSnap не заменяет.

## Модель безопасности и пределы

Недоверенными программа считает введенный адрес, ответы DNS, каждый ответ HTTP и каждое
перенаправление, содержимое страницы и любой пакет, переданный на проверку. Главные пределы такие:

- только публичные адреса IPv4 (сайты, доступные лишь по IPv6, не поддержаны);
- только порты 80 и 443 и только запросы GET;
- системные настройки прокси не используются;
- сжатые ответы и вложения (`Content-Disposition: attachment`) отклоняются;
- один ответ до 2 MiB, все ответы вместе до 16 MiB, не больше 50 запросов и сетевой бюджет 35 с;
- весь сбор прерывается через 70 с;
- рабочий процесс и всё, что он запускает, включая Edge, работают в Windows Job с пределом памяти
  1536 MiB, и закрытие задания завершает их все;
- нет JavaScript, iframe, форм, WebSocket, service workers, загрузок, пользовательского профиля и
  cookies.

Это не виртуальная машина. Неизвестную уязвимость Edge или Windows программа не сдержит, поэтому
заведомо вредоносные страницы снимайте на отдельной машине или в виртуальной. Модель угроз и порядок
сообщения об уязвимостях описаны в [SECURITY.md](SECURITY.md).

- английский интерфейс;
- подписанные манифесты и доверенные метки времени;

- отчет о пакете в PDF;
- поддержка Linux.

## Разработка

```powershell
python -B -m unittest discover -s tests -v
```

Модульным тестам интернет не нужен. Сетевую часть они проверяют на местном тестовом сервере, тесты
Windows Job идут только в Windows. CI запускает их в Windows на Python 3.12, workflow называется
`tests`. Файл `tests/gui_smoke.py` управляет настоящим окном, ходит в сеть к example.com и
запускается отдельно, вручную.

SealSnap разрабатывался закрыто в октябре 2026 года; перед первым открытым выпуском он прошел
независимый поиск дефектов, и найденное исправлено.
